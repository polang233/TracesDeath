# TracesDeath 功能清单

`[x]` 表示已有实现，`[ ]` 表示候选功能。候选项尚未排期，后续按实际需求选择。实现与扩展位置见 [核心设计](ARCHITECTURE.md)。

## 已实现

- [x] F001 死亡遗体：玩家死亡后生成带皮肤、装备和躺卧姿势的 Mannequin。
- [x] F002 物品接管：保存死亡事件实际掉落，尊重 `keepInventory` 和使用权限。
- [x] F003 原槽位界面：保留背包、快捷栏、护甲与副手布局，额外掉落分页显示。
- [x] F004 单格领取：按背包空间领取，剩余物品留在遗体中。
- [x] F005 一键原位恢复：恢复原槽位，被替换的玩家物品掉在脚下。
- [x] F006 一键背包收纳：通过配置切换，溢出的遗体物品掉在脚下。
- [x] F007 遗体信息：显示死亡者、死亡时间、死亡位置、剩余物品格数与经验。
- [x] F008 访问与界面保护：所有者限制、距离和世界检查、单人查看锁、只取不存。
- [x] F009 外观生命周期：现代版本非持久化实体、旧版残留展示清理、区块加载重建、缺失外观修复、取空消失。
- [x] F010 数据保存与恢复：原子文件保存、领取前后快照、失败锁定和登录核对。
- [x] F011 基础命令：`list`、`locate`、控制台人工恢复及基础补全。
- [x] F012 命令独立组织：命令分发、参数、权限和补全位于 `commands` 包。

## 体验与可配置性

- [x] F013 配置重载：管理员 `/td reload`，先校验再切换，关闭会话并重建展示，失败保留或恢复原设置；遗体和待完成领取从保存记录恢复。
- [x] F014 多语言与自定义文案：中英文 YAML，界面标题、按钮、实体名称与命令提示统一配置，支持重载。
- [x] F015 自定义界面物品：配置墓碑界面的按钮与分隔物品材质、名称、动态 Lore 和 CustomModelData，保留固定操作槽位。
- [ ] F016 死亡信息扩展：显示死亡原因、击杀者和遗体存在时长。
- [ ] F017 返回遗体指引：聊天坐标、指南针或粒子导航，支持多具遗体选择。
- [ ] F018 快捷交互：可配置潜行右键等操作触发指定领取方式。

## 玩法与领取规则

- [ ] F019 世界与场景规则：配置生效世界、区域及特殊死亡场景的处理策略。
- [ ] F020 所有者保护期：死亡后一段时间仅本人可领，到期后按规则开放。
- [ ] F021 授权领取：死者允许指定玩家或队友协助回收，配套权限检查。
- [ ] F022 遗体数量上限：按玩家或世界设置上限，明确超限遗物去向。
- [ ] F023 过期与清理策略：配置保留时长、到期提醒和剩余物品处理方式。
- [x] F024 经验回收：默认保存 50% 经验点；Q 单独领取，一键拾取或最后一件物品领取时结算，保存领取前后经验快照。
- [x] F025 物品接管规则：尊重死亡不掉落与 Paper 保留清单，名称或 Lore 命中排除规则时交给原版／其他插件处理。

## 管理、外观与集成

- [ ] F026 管理员查询：按玩家、时间、世界筛选遗体，查看详情与待恢复记录。
- [ ] F027 管理员处置：受权限控制的定位、打开、移除和清理操作，记录处理结果。
- [ ] F028 领取审计：记录领取人、物品变化、时间及异常，提供查询与保留期限。
- [ ] F029 外观配置：可配置名字显示、姿势、粒子、声音与点击范围。
- [x] F030 资源包墓碑原型：ItemDisplay 显示墓碑模型，复用现有记录、点击与领取流程。
- [ ] F031 第三方集成：PlaceholderAPI 查询、创建和领取事件、其他插件调用入口。
- [ ] F032 数据库保存：评估 SQLite 或数据库后端，定义旧记录迁移与恢复方式。
- [x] F033 版本回归流程：同一 JAR 在 Paper 1.12.2、1.19.4、1.21.9 自动检查创建、Shift 领取和强制重启恢复。

- [x] F034 资源包界面原型：上半区苔石面板，保留原版按钮及玩家背包布局。

- [x] F035 外观与版本选择：自动选择或配置 Mannequin（Paper 1.21.9+）、墓碑（Paper 1.19.4+）、箱子矿车（1.12+）。
- [x] F036 Shift 领取：遗体物品直接收入背包，空间不足时保留剩余物品；玩家背包保持只取不存边界。

- [x] F037 bStats：默认启用官方基础使用统计，服务 ID 34148。
- [x] F038 资源包模块：JAR 内置并导出包含 GUI 与墓碑素材的资源包，支持管理员命令测试发送。
- [x] F039 自定义资源映射：选择墓碑后按需生成 tombstone.yml，配置承载物品、CustomModelData、GUI 开关与标题字形。
